# 焼き込んだ文字（NotoSansJP-Regular SDF）

フォントは **Static**（固定）で焼いてある。**ここに無い文字は画面に出ない。**

レーン名や説明に新しい文字を足したのに表示されないときは、
まずこの一覧に入っているか確かめること。入っていなければ焼き直しが要る。

- 焼き込んだ文字数：**230字**
- サンプリングの大きさ：64／余白：6／描画：SDFAA
- アトラス：1024×1024 が**2枚**（ファイル 4.3MB）。1枚目に222字、2枚目に8字
  （217字で1枚目の縦が埋まっていたので、10本目の説明文の13字を足したら2枚目にあふれた）
- 元ファイル：`Assets/Fonts/NotoSansJP-Regular.ttf`
- 文字そのものは `Assets/Fonts/焼き込んだ文字.txt` にある（この文書は説明用）

## 焼き直す手順

1. `Assets/Fonts/焼き込んだ文字.txt` に足したい文字を書き足す
2. フォントアセットを選び、Atlas Population Mode を **Dynamic** に戻す
3. Inspector の Character Table を空にする（歯車メニュー → Clear Dynamic Data）
4. Font Asset Creator か `TryAddCharacters` で txt の文字を入れ直す
5. Atlas Population Mode を **Static** に戻す

### スクリプトで焼き直す（10本目で実施）

上の手順は、`unity eval` で次の順に呼んでも同じ結果になる（10本目の説明文の13字をこれで足した）。

1. txt に文字を書き足し、`AssetDatabase.ImportAsset` で読み直す
2. `fontAsset.atlasPopulationMode = AtlasPopulationMode.Dynamic`
3. `fontAsset.ClearFontAssetData(true)`（Clear Dynamic Data と同じ）
4. `fontAsset.TryAddCharacters(txt の全文字, out missing)`。`missing` が空であること
5. `fontAsset.atlasPopulationMode = AtlasPopulationMode.Static`
6. フォントアセットとアトラスの画像を `EditorUtility.SetDirty` して `AssetDatabase.SaveAssets`

焼いたあとに、焼く前の文字が1字も消えていないこと、`UIText.cs` の全文字列・全 LaneData の文字が
すべて入っていることを確かめる。時間がかかるので、eval の制限時間（5秒）を超えても処理は最後まで進む。
結果は Console に出して待つこと。

## どこから集めたか

- 画面にある TMP テキストの中身
- シーンのコンポーネントが持つ文字列（書式や固定文言）
- LaneData の laneName / description / hintText
- **`Assets/Scripts/UI/UIText.cs` の全文字列**
  固定文言・レーン名（英語）と、レーンの一言説明（日本語）。
  まだ作っていない10種のレーンぶんも先に入れてある

文言を足すときは `UIText.cs` に書く。文体の方針も同じファイルの冒頭にある。
